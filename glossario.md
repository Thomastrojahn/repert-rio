 ->Tipos de Sistemas de Informação

 ## Tipos de sistema de informação 

 -> Sistemas de Processamento de Transações (SPT).
 
 -> Sistemas de Informação Gerencial (SIG).

 -> Sistemas de Apoio à Decisão (SAD).
 
 -> Sistemas de Apoio Executivo (SAE/EIS).
 
 -> Sistemas Especialistas/Gestão do Conhecimento.
 
  ## O que cada um faz

 -> Sistemas de Processamento de Transações: Ele opera o nível operacional, que registra as atividades diárias das empresas, como, vendas, compras.
 
 -> Sistemas de Informação Gerencial: Eles atuan no nível gerencial intermédiario agrupando dados dos SPTs(Sistema de Processamento de Transações), para gerar relatórios estruturados e resumo de desempenho.
 
 -> Sistemas de Apoio à Decisão:Eles Utilizam dados internos e externos para fornecer análises complexas, ajudando gestores em decisões não estruturadas ou semiestruturadas.

 -> Sistemas de Apoio Executivo: Ele foca no nível estratégico, ele oferece uma visão geral e panorâmica da empresa para alta direção, facilitando decisões de longo prazo.

 -> Sistemas Especialistas/Gestão do Conhecimento: Ele apenas simula o conhecimento humano em áreas específicas para resolver problemas complexos.
